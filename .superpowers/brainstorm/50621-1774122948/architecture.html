Marine Tech App — Architecture Overview

Two projects, one Supabase backend

System Architecture
📱

Mobile App

React Native + Expo

- Service report forms
- Camera (HIN, engine hours)
- Job list & assignments
- Offline queue + auto-sync
- Push notifications
- Signature capture
Deployed via TestFlight (iOS) + APK (Android)
🗄️

Supabase Backend

Shared by both apps

Auth — email/password + invite links
Database — Postgres (jobs, reports, users)
Storage — photo buckets
Realtime — live job updates
Edge Functions — push notifications
Existing Supabase project or new one
💻

Admin Dashboard

Next.js Web App

- Review service reports
- Assign jobs to techs
- Manage tech accounts
- Invite new technicians
- View photos & signatures
- Export reports as PDF
Deployed to Cloudflare Workers
📱 ←→ 🗄️ Supabase SDK + offline queue 💻 ←→ 🗄️ Supabase SDK (server-side)

Database Tables

profiles

id, email, full_name, role (admin/tech), phone, avatar_url, invited_by, approved, created_at

jobs

id, assigned_to, boat_name, owner_name, marina, scheduled_date, status (new/in_progress/completed), notes, created_by, created_at

service_reports

id, job_id, tech_id, boat_name, owner_name, make_model, year, hin_number, marina, engine_make_model, engine_hours, oil_condition, fuel_system, battery_voltage, bilge_pump, service_types[], work_description, parts_used, hull_condition, gel_coat, propeller, zinc_anodes, concerns, signature_url, status (submitted/reviewed/approved), submitted_at

report_photos

id, report_id, photo_url, category (hin_plate/engine_hours/before/after/damage/other), caption, created_at

invites

id, email, invited_by, token, used, created_at, expires_at

notifications

id, user_id, title, body, type (job_assigned/report_reviewed/correction_needed), read, data_json, created_at

Build & Deploy Pipeline

Mobile App

1. Code in React Native + Expo
2. eas build --platform ios
3. eas build --platform android
4. eas submit → TestFlight / Play Store
5. Or share APK / TestFlight link directly

Admin Dashboard

1. Code in Next.js (existing project)
2. npx opennextjs-cloudflare build
3. npx wrangler deploy
4. Live at marinetech.grayyachts.com or similar
