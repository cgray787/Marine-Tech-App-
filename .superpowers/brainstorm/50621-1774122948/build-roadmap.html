Marine Tech — Full Build Roadmap

7 phases, from foundation to app on your techs' phones

Phase 1: Foundation

Week 1
1. Create Expo project (React Native) for the mobile app
2. Set up Supabase — new project or new schema in existing
3. Run all database migrations (11 tables, RLS policies, storage buckets)
4. Configure Supabase Auth (email/password)
5. Set up Expo Router with 3-tab layout (My Jobs, Service, PDI)
Result: Empty app shell with tabs that you can run on your phone via Expo Go

Phase 2: Mobile Core

Weeks 2-3
6. Build Login screen (anchor icon, dark inputs, gold button)
7. Build My Jobs tab — job cards with status badges
8. Build Service form — vessel info section (customer/boat dropdowns)
9. Build Service form — category tabs + checklist (BAD/GOOD toggles)
10. Build inline camera capture per checklist item
11. Build inline comment/notes per checklist item
12. Build General Notes + "Create Job" submission
13. Connect form → Supabase (insert report + checklist items + upload photos)
Result: Tech can log in, see jobs, fill out a full service form with photos, and submit

Phase 3: PDI

Week 3
14. Build PDI tab — same checklist UI, progress counter header (0/34)
15. Build PDI submission with "items need attention" warning
16. PDI-specific database writes (pdi_reports + pdi_checklist_items)
Result: Full Pre-Delivery Inspection workflow working

Phase 4: Job Summary

Week 4
17. Build read-only Job Summary screen (vessel card, systems card, work description)
18. Build photo gallery view
19. Build Export PDF functionality
20. Build Share functionality
Result: Completed jobs show full summary with PDF export

Phase 5: Offline + Notifications

Week 5
21. Implement expo-sqlite local storage + auto-save form progress
22. Build sync queue — offline submissions upload when back online
23. Set up Expo Push Notifications (expo-notifications)
24. Create Supabase Edge Functions for notification triggers
Result: App works without wifi, syncs later, techs get notified of new jobs

Phase 6: Admin Dashboard (Web)

Weeks 6-7
25. Build admin login + auth guard
26. Build dashboard home — stats, recent submissions, quick actions
27. Build reports list + detail view (same data as mobile Job Summary)
28. Build job assignment UI (create jobs, assign to techs)
29. Build tech management + invite flow
30. Build customers & boats management (feeds mobile dropdowns)
31. Build PDI reports view
32. Deploy to Cloudflare Workers
Result: You can review reports, assign jobs, manage techs from your browser

Phase 7: Ship It

Week 8
33. Configure EAS Build profiles (development + production)
34. Build iOS → submit to TestFlight → invite techs to test
35. Build Android → generate APK → share directly with techs
36. Set up EAS Update for over-the-air updates (push fixes without rebuilding)
Result: App on your techs' phones + iPad, admin dashboard live on the web

How The App Gets On A Phone

🍎 iPhone / iPad

1. You run eas build --platform ios
2. Expo builds the .ipa in the cloud (free)
3. You run eas submit --platform ios
4. App uploads to TestFlight
5. You invite techs by email in App Store Connect
6. Techs download TestFlight app → install Marine Tech
7. Future updates: eas update pushes OTA
⚠️ Requires Apple Developer account ($99/year)

🤖 Android

1. You run eas build --platform android
2. Expo builds the .apk in the cloud (free)
3. Download the .apk file
4. Send .apk to techs (AirDrop, email, or link)
5. Techs tap the .apk → "Install from unknown sources"
6. App installed — done
7. OR submit to Play Store for official distribution
✓ No developer account needed for direct APK sharing
